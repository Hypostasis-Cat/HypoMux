## 本次改动

1. 将向客户端写入失败、短写与上游读失败分开。客户端中断不增加节点故障、不触发故障冷却，也不记作成功连接；显式上游响应错误仍可触发保护。新增中英文诊断说明。
2. DNS／同域会话发现池由最多 8 个扩大到 32 个，仍保留公共地址过滤、最短 TTL、跨网卡及地址族交错和周期轮换。每张网卡先排除地址族不支持、过期、重复及当前原节点，再选最多 8 个做验证。短测预算、任务并发和真实流量试用上限不变。
3. Windows Core 构建通过 linker 注入当前 Git 提交号，后续日志可以明确定位构建来源。

外部第三方 IP 数据库、跨 CDN 域名替换、HTTPS 内容短测及自动终止慢连接均不在本次范围；不要将发布说明写成全 CDN 加速或保证跑满带宽。

## 发布前实机验收

- 下载至少 5 分钟，暂停后继续，最后退出 Steam。确认客户端中断诊断与真正的节点故障分开，原路下载仍正常。
- 下载期间开关优选，并停止／重新启动聚合。确认设置保存、流量继续，诊断显示正确 Core 版本与提交号。
- 使用同一下载任务做关闭→开启→关闭的稳定窗口对比，记录平均吞吐和失败；磁盘解压阶段不用于比较。
- 检查工具箱开关、详情返回、深浅主题下的下拉菜单和禁用状态。
- 发布标签、版本号和签名安装包需在正式发布时确认；本文不表示已创建 Release 或完成安装包实机验收。
