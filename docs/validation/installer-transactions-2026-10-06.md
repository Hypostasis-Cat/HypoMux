# 安装事务与原生更新助手验收（2026-10-06）

## 已实现

保留 NSIS 分发格式与更新协议，把核心文件替换改为持久化事务。新安装与覆盖升级共用备份/校验/恢复流程，
不再提前删除受保护 Core 文件，也不提前运行旧卸载器。服务健康检查和卸载信息写入成功后才提交。
退出失败页、取消和下一次安装均有恢复入口；新卸载器先检查未完成的事务。

更新器不再生成 CMD 脚本。原生助手重新验证签名、锁定安装包、取得父进程句柄并发出原子就绪确认，
主程序才通过原有生命周期退出。取消、失败和退出等待超时保留安装包及报告；下载与安装请求互斥。
WebView2 引导程序退出码和安装后的可用性都必须通过；机器安装不能误用管理员账户的个人运行时。

## 实际验证

- 事务测试通过：每个替换边界故障、prepared 状态恢复、重复恢复、提交后不回退、载荷/备份损坏、
  恢复失败后保留备份并重试、安装后校验、日志路径逃逸、服务停止失败后恢复未改动安装的配置。
- Windows 临时文件测试通过：只读/隐藏属性与 ACL 保存恢复、私有事务目录、拒绝硬链接、
  旧目录清理保留未知文件和当前安装。ACL 测试使用普通宿主权限执行，沙箱受限令牌无法访问新私有 ACL 目录。
- 真实 NSIS 控制流夹具通过：首次安装没有旧文件时跳过探测、旧/新/受保护 Core 路径、空输出失败、
  真实写锁、旧 UI 关闭失败、WebView2 返回失败及“返回 0 但仍未安装”。夹具不操作真实服务或安装目录。
- 更新、签名与退出生命周期相关测试通过：未签名文件拒绝、中文/空格/百分号/& 路径、原子确认、
  重复请求拒绝、取消/非零退出/父进程等待失败保留文件、成功才清理安装包。
- 新编译桌面二进制的真实命令入口测试通过：无界面拒绝非法安装范围；无界面拒绝未签名更新包，
  写入持久化报告和失败确认，保留原安装包。
- 修改涉及的 Go 包与桌面入口 `go vet` 通过；桌面编译通过；完整 NSIS `/WX` 编译通过。
- PowerShell 诊断收集器语法检查通过；`git diff --check` 通过。

完整 `internal/services` 测试另发现以下失败：热点只读预检在沙箱外复测通过；
`TestDesktopIPv6ICMPRealLoopback` 和 `TestRuntimeBindingRealCoreIPv6Loopback` 在宿主权限下仍失败。
两项涉及本机 IPv6 回环通信，具体原因尚未定位；未改动其实现，不能声称全项目测试全部通过。

## 发布前系统验收边界

本机没有运行真实安装、卸载、服务替换、UAC 交互或模拟断电，也没有发布正式安装包。
仍须在隔离 Windows 10/11 环境验收：干净机器、v2.7.0 覆盖、旧 Python/Inno 与重复目录迁移、
自定义目录、运行/停止/禁用服务、UAC 取消、WebView2 缺失、重启后恢复及已签名正式包的端到端自动更新。

`.cache/setup-validation/HypoMux-transaction-validation.exe` 仅为本地编译验证产物，
不是正式签名发布包；其 Core 载荷来自本机现有 bin，不能直接发给用户作为正式版本。
用户报告中的 v2.7.0 故障没有记录安装器内部失败码，仍不能把某一已修复缺陷认定为该机器的唯一根因。
