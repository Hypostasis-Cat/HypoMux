# 拒绝连接规则（Issue #78）

自定义分流规则的出口增加「拒绝连接 / Reject connection」，支持进程名、域名（含子域名）和 IP/CIDR。支持单条编辑、批量添加、规则备份及恢复。

拒绝规则与普通分流规则使用相同的匹配顺序、优先级和更具体匹配规则，不会无条件抢占放行规则。代理兼容绕过仍遵循已有机制：进程、域名及具有显式优先级的 IP 规则可覆盖该绕过；默认优先级的 IP 规则不改变此行为。应用自身防循环绕过和 DNS 接管仍先执行。

规则仅作用于进入 TUN 的流量，不是系统防火墙。域名拒绝依赖可识别的域名信息；本功能在路由阶段拒绝连接，不返回 NXDOMAIN，也不保证不分配 FakeIP。已有连接不会因编辑规则而主动断开，验证时需建立新连接。

启动时预留空拒绝规则集，新增、编辑、禁用及删除拒绝规则通过现有规则集热更新。旧主配置没有拒绝规则集时，会沿用出口变更的重启提示；DNS 模式原先没有启用 FakeIP 时，新增域名规则仍可能需要重启。

验证覆盖：设置保存和重新加载、备份恢复、前端选择与自动保存、三种 DNS 策略下的主配置生成及 sing-box check、进程/域名/IPv4/IPv6 匹配、放行例外、代理兼容、禁用和删除热更新。规则命中测试使用明确的连接元数据，不代替真实 TUN 环境的端到端网络验证。
